老北京麻辣串串香 · 点单小程序预览版

这不是重写的 Demo —— 视图换成 HTML，业务代码直接跑小程序源码： utils/cart.js、services/order.js、services/menu.js、 utils/auth.js、mock/menu.js、mock/coupon.js， 共 9 个模块由构建脚本内联进来。

先跑一遍主流程

  1. 点单：点左侧「串串 · 荤」，右侧会自动滚到对应区块；反过来滚右侧，左侧高亮也会跟着走
  2. 点「秘制麻辣牛肉串」的 + → 弹辣度层 → 选 特辣 ×2 → 加入购物车
  3. 再点同款 + → 选 微微辣 ×1 —— 购物车里会出现两条不同辣度的明细
  4. 点「土豆片」的 +（无规格菜品）→ 直接加购，数字会跳
  5. 底部黑色购物车条 → 进购物车，换锅底 / 勾蘸料 / 改数量 / 写备注，金额实时变
  6. 去结算 → 点「优惠券」选一张 → 提交订单 → 弹出模拟支付
  7. 确认支付 → 跳订单详情：出现取餐码，状态每 5 秒自动推进（已支付 → 接单 → 涮煮 → 可上桌）
  8. 订单页切换「进行中 / 已完成」，已完成订单可「再来一单」把明细回填购物车

这里能看到什么

· 同串不同辣度：明细唯一键是 dishId#spicyId，所以「特辣×2」和「微微辣×1」是两行、各自计价

· 金额全整数分：菜品 + 锅底 + 自取打包费 − 优惠券，不会出现 0.30000000000000004

· 状态机：UNPAID → PAID → ACCEPTED → COOKING → READY → DONE，可分支 CANCELED

· 数据持久化：购物车与订单落在 localStorage，刷新页面不丢

与真机的差异

· 长按删除改成了右上角 ✕（桌面上不好长按）

· 「模拟支付」沿用小程序里的 MOCK_PAY 开关，不发起真实微信支付

· 订阅消息、拨号、打开地图为模拟提示

· 微信开发者工具才能跑的：真机预览、vConsole 调试、性能面板、分包体积审计

装完微信开发者工具 → 导入项目 → 选工作区里的 lbz-chuanchuan 目录 → 编译即可。 AppID 先用「测试号」，真机预览需换真实 AppID。
