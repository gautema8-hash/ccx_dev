# 老北京麻辣串串香 · 连锁运营管理系统
# 使用说明

> 适用对象：总部运营、区域经理、门店店长/店员、加盟商。
> 访问地址：`https://<你的域名>/admin`（本地：`http://127.0.0.1:3000/admin`）
> 手机浏览器可用，界面自适应。

---

## 1. 登录与账号

### 1.1 登录

打开 `/admin`，输入**账号 + 密码**登录。

- 登录失败文案统一为「账号或密码错误」（不区分账号是否存在，防账号枚举）。
- 同一 IP 5 分钟内最多尝试 40 次；同一账号连续失败 5 次锁定 15 分钟。
- 令牌有效期 2 小时，无操作会自动续期（刷新令牌 7 天）。

### 1.2 首次登录强制改密

新建或重置过密码的账号，`must_change_pwd = 1`。登录后**只能改密码**，改完才进入系统。

密码规则：
- 至少 8 位
- 必须同时包含字母和数字
- 不能以 `123456` / `password` / `admin` 开头

## 3. 各功能页操作指南

### 3.1 📊 经营看板

| 内容 | 说明 |
| --- | --- |
| 今日关键指标 | 订单数、营业额、待接单、退款申请 |
| 门店维度统计 | 各门店今日订单与营业额 |
| 你的数据权限 | 明确展示你能看到的范围 |

### 3.2 🧾 订单管理

| 操作 | 说明 |
| --- | --- |
| 筛选 | 按状态、日期、关键词（订单号/桌号/取餐号） |
| 接单 | `PAID → ACCEPTED` |
| 制作 / 出餐 / 完成 | 依次推进（`ACCEPTED → COOKING → READY → DONE`） |
| 拒单 | 已支付的订单会自动退款 |
| 退款审核 | 在「退款」区通过或驳回；通过后订单转为 `CANCELED` |

**注意**：
- 状态必须按顺序推进，跳步会提示「当前状态（XX）不能执行「YY」」。
- 订单推进到「完成」后自动给顾客发积分（实付元数）。
- 店员角色只能接单与推进，不能拒单/退款。

### 3.3 🎫 团购券核销

**核销步骤**：

1. 顶部选择**核销门店**（必须与顾客消费门店一致）
2. 在「券码」输入框输入券码（如 `MT1688888888`），回车或点「核销」
3. 成功会显示：套餐名、面值、门店、核销时间
4. 下方「核销记录」可查看本店历史核销，支持撤销（需 `voucher:refund` 权限）

| 场景 | 系统表现 |
| --- | --- |
| 券码格式错误 | 提示「券码格式不正确（应以 MT 开头，共 10-20 位）」 |
| 券已被核销 | 提示**原始核销时间与门店**，便于追责 |
| 门店不在营业时间 | 提示「门店当前未营业，请在营业时间内核销」 |
| 同一张券被并发提交 | 只有一次成功（数据库唯一键兜底） |
| 核销门店超出你的权限 | 提示「无权操作该门店」 |

**撤销核销**：撤销会同步调用券商退款接口并写审计日志。撤销后该券码**不能再次核销**（防套现）。

> 通道标识：`店员核销`（本页操作）/ `顾客自助`（顾客在小程序自己核销）。两者共用同一套防重逻辑。

### 3.4 🎟️ 优惠券

| 区域 | 操作 |
| --- | --- |
| 券模板列表 | 查看名称、类型、面额、门槛、适用范围、发放方式、已发/总量、已使用、核销率 |
| 新建/编辑券 | 需要 `coupon:write`（区域经理及以上） |
| 上下架 | 停用后顾客不可领、不可用 |
| 定向发放 | 需要 `coupon:issue`；支持按**用户 ID / 手机号 / openid** 三种方式，单批最多 500 人 |
| 使用统计 | 发放数、使用数、核销率 |

**券型说明**：

| 类型 | 抵扣口径 |
| --- | --- |
| 现金券 `CASH` | 抵扣 = min(面额, 菜品 + 锅底 + 打包费) |
| 锅底券 `SOUP` | 只对锅底费抵扣 |
| 折扣券 `DISCOUNT` | 按 `(菜品 + 锅底) × (100 - 折扣值) / 100`（填 `88` = 8.8 折） |

**新建券的关键约束**：

| 约束 | 说明 |
| --- | --- |
| 折扣值 | 必须在 1 ~ 99 之间 |
| 面额与门槛 | 有门槛时，面额不得大于门槛 |
| 适用范围 | 不选门店 = 全品牌通用；选定门店 = 仅这些门店可用 |
| **门店范围越权** | 不能把券限定到自己无权管理的门店（即使有 `coupon:write`） |
| 限领 | 总量、每人限领、每日限领 |

**领券中心开关**：勾选后券会出现在小程序「领券中心」，顾客可自领；不勾选则只能定向发放。

### 3.5 🎨 主题管理

主题决定小程序整体配色（品牌活动日 / 节假日 / 会员日等）。

| 区域 | 说明 |
| --- | --- |
| 顶部预览 | 实时展示当前生效主题：横幅、角标、主色/辅色/底色色块 |
| 主题列表 | 名称、类型、级别（品牌级/门店级）、优先级、生效时间、状态、主色 |
| 预置模板 | 标准主题 / 品牌活动日 / 国庆节假日 / 会员日，**一键套用**不用自己调色 |

**操作**：

| 操作 | 效果 |
| --- | --- |
| **立即启用** | 目标主题优先级置 1000 并清除时间窗；同层级其它主题降为 0（**不删除，可随时切回**） |
| 停用 / 启用 | 控制是否参与解析 |
| 删除 | 删除主题（需 `theme:write`） |
| 新建自定义 | 设置名称、类型、级别（品牌级/门店级）、令牌色值、生效时间窗、优先级 |

**生效优先级**：

```
门店级主题  >  品牌级主题  >  默认主题
（同级别内：在生效时间窗内、启用中的，取优先级最大者）
```

所以：
- 想让**全品牌**换肤 → 建品牌级主题（`storeId` 留空）
- 想让**某家店单独**换肤（如开业庆）→ 建门店级主题，选该门店

**安全**：令牌键只接受白名单（15 个），色值只接受安全字符，无法注入 `url()` / `javascript:` 等。

### 3.6 🍢 菜单与库存

**分工**：总部维护「卖什么、指导价」，门店维护「有多少货、今天卖不卖、要不要改价」。

| 列 | 说明 |
| --- | --- |
| 菜品 / 分类 | 来自品牌菜单 |
| 指导价 | 总部价 |
| 本店售价 | 门店改价后的价格（改过会标「门店改价」） |
| 本店库存 | **可直接编辑**，点「保存库存」批量提交 |
| 已售 | 本店销量 |
| 状态 | 「总部上架/下架」+「本店在售/停售」两个维度 |

| 操作 | 说明 |
| --- | --- |
| 保存库存 | 批量提交本页所有库存（需 `dish:stock`） |
| 本店停售 / 本店开卖 | 只影响**当前门店**，不影响品牌菜单和其它门店 |
| 门店改价 | 通过 `POST /admin/store-dishes` 提交 `priceOverride`（后台页面当前提供库存与停售的界面入口，改价走接口；`TODO`：如需运营自助改价可在后台补充输入项） |

> 改价/改库存/上下架后，菜单缓存会立即失效，小程序最多 60 秒内看到最新结果。

### 3.7 🏪 门店管理

| 操作 | 说明 |
| --- | --- |
| 查看门店 | 名称、编码、类型（直营/加盟）、加盟商主体、大区、城市、地址、电话、人均、营业状态、今日订单与营业额 |
| 新增/编辑 | 需 `store:write`（仅品牌超管） |
| 停启用 | 停用后不出现在顾客端「附近门店」 |
| 同步菜单 | 把品牌菜单同步到该门店（新开门店用） |

**门店类型**：

| 类型 | 说明 |
| --- | --- |
| 直营 `DIRECT` | 品牌自营 |
| 加盟 `FRANCHISE` | 填写「加盟商」主体名称；加盟商账号只能看到自己这家店 |

### 3.8 👥 员工与权限

| 操作 | 说明 |
| --- | --- |
| 新增员工 | 需 `staff:write`（仅品牌超管） |
| 编辑 | 改姓名、角色、大区、授权门店 |
| 重置密码 | 重置后首次登录强制改密；**新密码只显示一次** |
| 停用 / 启用 | 停用后无法登录 |

**新增员工表单**：

| 字段 | 说明 |
| --- | --- |
| 账号 | 小写字母/数字/`.`/`_`/`-`，3~32 位 |
| 姓名 / 手机 | — |
| 角色 | 5 选 1 |
| 大区 | 角色为「区域经理」时必填，决定其可见门店 |
| 授权门店 | 店长/店员必选至少 1 家；**只能选你自己有权管理的门店** |
| 初始密码 | 留空自动生成 `Lbz@XXXXXX` |

**安全约束**：
- 只有品牌超管能创建/修改品牌超管账号（防提权）。
- 不能给员工授权你自己都管不到的门店。
- 状态标签会显示「待改密」「已锁定」。

### 3.9 📜 审计日志

需 `audit:read`（品牌超管、区域经理）。

| 内容 | 说明 |
| --- | --- |
| 操作日志 | 谁、在哪家店、什么时间、做了什么动作、目标对象、IP、UA、requestId |
| 登录日志 | 登录成功/失败，失败原因（`NO_SUCH_ACCOUNT` / `BAD_PASSWORD` / `LOCKED` / `DISABLED` / `IP_RATE_LIMITED`） |

支持按动作、员工、时间范围筛选。**所有管理端写操作都会留痕**。

## 4. 权限速查

| 你是 | 能做什么 | 不能做什么 |
| --- | --- | --- |
| 品牌超管 | 全部 | — |
| 区域经理 | 看本大区订单/统计；改库存；推进和取消订单；建券与发券；管主题；核销；查审计 | 改品牌、改门店、管员工、撤销核销 |
| 店长 | 看本店订单/统计；改本店库存；推进和取消订单；核销 | 建券、改主题、管员工、查审计 |
| 店员 | 看本店订单；推进订单；核销 | 改库存、取消订单、看统计以外的经营数据 |
| 加盟商 | 看本店订单/统计；改本店库存；推进和取消订单；核销 | 看别家门店的任何数据；建券；管员工 |

## 5. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 登录后只能改密码 | 该账号待改密 | 改完密码即可进入 |
| 侧边栏少了很多菜单 | 你的角色权限有限 | 属正常；需要更多权限请联系品牌超管 |
| 门店列表是空的 | 你的账号没有被授权任何门店 | 联系品牌超管分配门店 |
| 看不到某家店的数据 | 该店不在你的授权范围 | 属**数据隔离**设计，不是故障 |
| 提示「无权操作该门店」 | 操作了范围外的门店 | 先切换顶部门店选择器到授权门店 |
| 提示「尝试过于频繁」 | 登录触发 IP 限流（40 次/5 分钟） | 等 5 分钟；不要连续重试 |
| 提示「账号已被锁定」 | 连续失败 5 次 | 等 15 分钟自动解锁，或让超管重置密码 |
| 页面一直转圈 | 接口无响应 | 刷新；检查服务端 `/ready`；超过 15 秒会自动中断 |
| 改了库存顾客端没变 | 菜单缓存 | 最多 60 秒生效；可让顾客下拉刷新 |
| 主题改了小程序没变 | 小程序本地缓存 5 分钟 | 下拉刷新或重进小程序 |
