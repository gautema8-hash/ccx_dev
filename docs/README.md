## 约定

- 文档以**当前代码**为准描述系统现状，不描述未实现的设想。
- 业务侧尚未确认、代码中也无依据的信息，一律用 `TODO` 标注并集中在各文档末尾的「待确认事项」表中。
- 数值类指标（性能、容量、SLA）均标注来源：实测值来自测试套件，目标值若未确认则标 TODO。
