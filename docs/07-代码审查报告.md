## 3. 已修复项详述

### 3.1 MP-01 结算页优惠抵扣口径（P1）

**修复前**：

```js
recalc() {
  const discount = mockCoupon.calcDiscount(coupon, summary);   // ← 本地 mock 口径
  const usable = this.data.coupons.filter(c => summary.goodsAmount + summary.soupFee >= c.threshold);
}
```

**修复后**：真实后端走 `POST /coupons/usable`，用服务端返回的 `estimateDiscount`；已选券若不在可用列表中则清空（门店不适用 / 未达门槛 / 已用完）；请求失败按"不用券"展示，不臆造金额。同时用金额上下文 key 做去重，避免购物车微调时反复打接口。

**为什么重要**：领券中心分包页早就用了服务端口径，结算页没跟上，两处不一致是典型的"同源逻辑分裂"。

### 3.2 MP-05 切换门店后购物车校正（P2）

新增 `cart.reprice(dishMap)`：

```js
s.items = s.items.filter((i) => {
  const d = dishMap[i.dishId];
  if (!d || Number(d.stock) <= 0) { removed++; return false; }   // 本店不卖/售罄
  if (Number(i.price) !== Number(d.price)) { i.price = Number(d.price); changed++; }
  const cap = Math.min(99, Number(d.stock) || 99);
  if (i.count > cap) { i.count = cap; capped++; }
  return true;
});
```

点单页加载菜单成功后调用，有移除时 toast 提示用户。

### 3.4 MP-12 超时未支付订单自动关单（P1）

**修复前**：`prepay()` 检测到超时只 `throw`，订单仍是 `UNPAID`，库存已被扣但永不释放。

**修复后**：把取消逻辑抽成与 `ctx` 无关的 `closeUnpaidOrder(orderId, operator, reason)`，三条路径共用：

```js
// 用户主动取消
await closeUnpaidOrder(orderId, 'user', reason);

// 支付超时：先关单再提示
if (orderRoute.isPayExpired(order)) {
  await orderRoute.closeUnpaidOrder(order.id, 'system', '超时未支付自动关闭');
  throw bizError(CODES.STATE_CONFLICT, '订单已超时关闭，请重新下单');
}

// 惰性清理（订单列表/详情）+ 60s 定时兜底（closeExpiredOrders）
```

关单内部用条件更新（`status='UNPAID'`），**多实例同时跑也只会有一个成功**，因此定时任务在集群下无需选主。

**回归**：新增 `[10b]` 用例 5 项——下单扣库存 → 改 `created_at` 到超时点前 → prepay 被拒（40901）→ 库存已回滚 → 订单状态 `CANCELED`。

### 3.3 ADM-01 401 重放递归（P2）

```js
if (res.status === 401 && !opt.__retried) {
  return doRefresh().then(function () {
    return api(path, Object.assign({}, opt, { __retried: true }));
  });
}
if (res.status === 401) logout();
```

## 4. 审查中确认的正面实践（保留）

| 端 | 实践 | 说明 |
| --- | --- | --- |
| 小程序 | 统一网络层 | token 注入、401 静默重登**全局去重**、幂等请求才重试、并发去重、离线快速失败 |
| 小程序 | 金额用「分」整数 | 全程无浮点 |
| 小程序 | 加购按库存封顶 | `min(99, dish.stock)`，规格弹层反复加购也挡住超卖 |
| 小程序 | 主题降级 | 拉不到主题不影响点单，回落默认令牌 |
| 小程序 | 定位降级 | 拒绝授权不报错，`needLocation` 引导开启 |
| 小程序 | 分包 + 预加载 | 优惠券分包，`preloadRule` 在「我的」「结算」预取 |
| 小程序 | tab 页订阅短路 | `visible` 开关，隐藏时不 setData |
| 管理端 | 全量 `esc()` | 所有动态插值均转义 |
| 管理端 | 按权限渲染菜单 | 无权限的菜单不出现（不是点了才报错） |
| 管理端 | 门店选择器全局生效 | 避免"以为在操作 A 店，实际改了 B 店" |
