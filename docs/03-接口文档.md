# 老北京麻辣串串香 · 连锁点单系统
# 接口文档

> 版本：v1.0　｜　基准前缀：`/miniapp/v1`（可由 `API_PREFIX` 配置）
> 本文基于 `server/src/app.js` 的实际路由整理。字段名以代码为准。

---

## 1. 通用约定

### 1.1 请求

| 项 | 说明 |
| --- | --- |
| 协议 | HTTPS（生产） |
| 前缀 | `/miniapp/v1` |
| 内容类型 | `application/json; charset=utf-8` |
| 请求体上限 | 256 KB（`BODY_LIMIT`），超限返回 HTTP 413 |
| 请求超时 | 服务端 15 s |
| 追踪 | 请求头 `X-Request-Id`（可选，不传由服务端生成），响应头回传 |

### 1.2 响应

**所有业务响应均为 HTTP 200 + `code`**（业务错误不用 HTTP 状态码表达，避免客户端误判为网络错误而重试非幂等操作）。

```jsonc
// 成功
{ "code": 0, "message": "ok", "data": { } }

// 失败
{ "code": 40001, "message": "请先选择门店", "data": null, "detail": null }
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | number | `0` 成功，非 `0` 见错误码表 |
| `message` | string | **可直接 toast 给用户的中文提示** |
| `data` | any | 业务数据 |
| `detail` | any | 排障细节（可选） |

### 1.3 鉴权方式

| 类型 | 头 | 说明 |
| --- | --- | --- |
| 用户令牌 | `Authorization: Bearer <access_token>` | 小程序 `wx.login` → `code2session` 换取 |
| 员工令牌 | `Authorization: Bearer <access_token>` | 管理端账号密码登录换取（**与用户令牌体系隔离，不可互换**） |
| 可选登录 | 同一头，有则解析无则跳过 | 菜单、门店、主题、领券中心 |
| 幂等键 | `Idempotency-Key: <唯一串>` | 仅下单接口，重试返回同一订单 |
| 旧单店兼容 | `X-Admin-Token` | **已废弃**，仅保留兼容开关 |

**鉴权分层**：

```
公开        —— 健康检查、登录、门店、菜单、主题、支付回调
optionalAuth —— 同上（带令牌则附带用户信息，如券的已领状态）
requireAuth  —— 用户维度接口（订单、券、核销、资料、支付）
requireStaff —— 管理端全部接口（内部再按 rbac 校验权限点与门店范围）
```

### 1.4 错误码

| code | 名称 | HTTP | 含义 | 客户端建议 |
| --- | --- | --- | --- | --- |
| 0 | OK | 200 | 成功 | — |
| 40001 | PARAM_INVALID | 200 | 参数错误 / 业务校验失败 | toast `message` |
| 40100 | AUTH_FAILED | 401（未登录时） | 未登录 / 令牌失效 / 口令错误 | 用户端静默重登重放；管理端跳转登录 |
| 40300 | FORBIDDEN | 403 | 无权限点 / 门店越权 / 未改密 | toast 提示，不重试 |
| 40400 | NOT_FOUND | 404 | 资源不存在 | toast 提示 |
| 40901 | STATE_CONFLICT | 200 | 状态冲突（跳步流转、重复核销、券已使用） | 刷新后重试 |
| 40902 | ORDER_DUPLICATED | 200 | 下单重复（幂等命中） | 返回同一订单 |
| 42001 | STOCK_NOT_ENOUGH | 200 | 库存不足 | 提示调整数量 |
| 42002 | COUPON_UNAVAILABLE | 200 | 券不可用 / 已领完 / 超领取上限 | toast 提示 |
| 42003 | AMOUNT_EXCEEDED | 200 | 金额超限 | toast 提示 |
| 42900 | RATE_LIMITED | 429 | 触发限流 | 按 `message` 提示等待 |
| 50000 | SERVER_ERROR | 500 | 服务端异常 | 上报 `X-Request-Id`，重试幂等请求 |
| 50200 | UPSTREAM_ERROR | 200 | 上游（微信/美团）异常 | toast 提示 |
| 50300 | UNAVAILABLE | 503 | 过载 / 依赖不可用 | 稍后重试 |

### 1.5 分页

| 参数 | 默认 | 约束 |
| --- | --- | --- |
| `page` | 1 | 1 ~ 10000 |
| `size` | 20 / 30 / 50（按接口） | 1 ~ 100（部分接口 200） |

超出范围自动钳制，不会导致 OFFSET 溢出。

## 4. 门店与菜单（连锁）

### GET /stores

鉴权：可选登录　｜　权限：无

请求参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `lat` `lng` | number | 坐标（gcj02）。**不传也能返回列表**，只是没有距离与排序 |
| `type` | string | `DIRECT` 直营 / `FRANCHISE` 加盟 / 空=全部 |
| `keyword` | string | 匹配门店名/地址/城市 |

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `list` | array | 门店列表（见下） |
| `total` | number | 条数 |
| `center` | object\|null | 传入的坐标 |
| `needLocation` | boolean | `true` 表示未拿到坐标，前端可引导开启定位 |

门店对象：

| 字段 | 说明 |
| --- | --- |
| `id` `brandId` `code` `name` | 标识 |
| `type` / `typeText` | `DIRECT`/`直营店`、`FRANCHISE`/`加盟店` |

| `distanceKm` / `distanceText` | 距离（**仅有坐标时返回**） |

排序：营业中优先 → 距离升序；50 km 半径内最多 20 家。

### GET /stores/:id

鉴权：可选登录。返回门店对象 + `brand`（品牌信息）。
错误：`40400 门店不存在`

鉴权：可选登录

响应 `data`：

| 字段 | 说明 |
| --- | --- |
| `brand` | `{id, name, logo, notice, contact}` |

| `shop` | 当前门店（兼容旧字段） |
| `store` | 当前门店（含 `type`/`typeText`/`franchisee`/`openNow`） |
| `categories` | `[{id, name, emoji, dishes: [...]}]`，已过滤门店停售 |
| `soups` | `[{id, name, price, emoji, description, recommended}]` |
| `dips` | `[{id, name, price, emoji}]` |
| `spicyOptions` | `[{id, name, color}]` |
| `totalDishes` | 菜品总数 |
| `updatedAt` | 服务端时间戳 |

菜品对象：`{id, categoryId, name, desc, emoji, image, price(分), unit, spicy, stock, sold, tags[], soldOut}`

> 价格与库存已按 `mp_store_dish` 覆盖计算（`COALESCE`），即「本店真正价格与库存」。

## 6. 优惠券

### GET /coupons/center

鉴权：**可选登录**（未登录也能浏览；登录后带「我已领几张」状态）　｜　参数：`storeId`

响应 `data`：

| 字段 | 说明 |
| --- | --- |
| `list` | 券模板数组 |
| `total` | 条数 |

券模板对象：

| 字段 | 说明 |
| --- | --- |
| `id` `name` `type` | `type`: `CASH` 现金 / `SOUP` 锅底 / `DISCOUNT` 折扣 |
| `value` / `valueText` | 面额（分）/ 展示文案（`8.8折` 或 `¥10.00`） |
| `threshold` / `thresholdText` | 门槛（分）/ 文案 |
| `scope` `storeIds` `storeScopeText` | 适用范围（空数组 = 全品牌通用） |
| `total` `issued` `remain` `soldOut` | 库存与发放 |
| `perUser` `dayLimit` `receiveEnabled` | 限领 |
| `receivedCount` `todayCount` `canReceive` | 当前用户维度（未登录为 0 / true 判定按游客） |

> 限定门店的券只在对应门店展示。

### POST /coupons/:id/receive

鉴权：用户　｜　限流：20 次/分钟　｜　请求 `{ storeId }`　｜　响应：券模板对象

错误：
- `42002 每人最多领取 N 张`
- `42002 今日已达领取上限`
- `42002 优惠券已被领完`
- `42002 该券不适用于当前门店`

### GET /user/coupons

鉴权：用户

| 参数 | 说明 |
| --- | --- |
| `status` | `UNUSED` / `USED` / `all`（默认 `UNUSED`） |
| `storeId` | 门店 |
| `withContext` | `1` 时附带订单上下文计算可用性 |
| `goodsAmount` `soupFee` | `withContext=1` 时必填（分） |

响应：券数组，附加

| 字段 | 说明 |
| --- | --- |
| `userCouponId` | 用户持券记录 id |
| `usable` | 是否未使用 |
| `applicable` | 当前订单是否可用（仅 `withContext=1` 且未使用时） |
| `inapplicableReason` | 不可用原因（门店不适用 / 未达门槛 / 无可抵扣金额） |
| `estimateDiscount` | 预计抵扣（分） |

### POST /coupons/usable

鉴权：用户　｜　请求 `{ storeId, goodsAmount, soupFee }`

响应 `data`：`{ list, best, total }`，`list` 按 `estimateDiscount` 倒序。

**抵扣口径**（与下单完全一致）：

| 券型 | 计算 |
| --- | --- |
| `CASH` | `min(value, goodsAmount + soupFee)` |
| `SOUP` | `min(value, soupFee)` |
| `DISCOUNT` | `round((goodsAmount + soupFee) × (100 - value) / 100)`（`value=88` 即 8.8 折） |

最终结果再 `min(抵扣, 订单金额)`，不出现负数实付。

## 8. 订单

### POST /orders

鉴权：用户　｜　幂等：`Idempotency-Key`　｜　限流：5 笔/15 分钟（按用户）

请求：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `items` | array | 是 | `[{dishId, spicyId, count}]` |
| `soup` | object | 是 | `{id}` 锅底（必选） |
| `dips` | array | 否 | `[{id}]` |
| `diningType` | string | 是 | `dinein` 堂食 / `takeout` 自取 |
| `tableNo` | string | 堂食必填 | 桌号 |
| `peopleCount` | number | 否 | 默认 2 |
| `remark` | string | 否 | ≤ 100 字 |
| `coupon` | object | 否 | `{id}` 优惠券 |
| `storeId` | string | 否 | 不传取默认门店（直营优先 + 编码最小） |
| `parentOrderId` | string | 否 | 加菜场景挂上游订单 |
| `amount` | object | 否 | **仅用于校验，服务端不采信，一律重算** |

响应 `data`：`{ id, orderNo, pickupNo, status, amount:{goods, soupFee, packFee, discount, pay}, ... }`

错误：
- `40001` 空购物车 / 未选锅底 / 堂食未选桌号 / 菜品不存在 / 数量非法 / 菜品已下架 / 本店已停售 / 未选辣度 / 金额超限
- `42001 「X」库存不足`
- `42002` 券不可用
- `40902` 幂等命中（返回同一订单）

### GET /orders

鉴权：用户　｜　参数：`filter=all|ongoing|done`、`page`、`size`

### GET /orders/:id

鉴权：用户（**只能看自己的**）　｜　返回订单详情 + `timeline` 时间轴

### POST /orders/:id/cancel

鉴权：用户　｜　**仅未支付可取消**

### POST /orders/:id/urge

鉴权：用户　｜　需已支付　｜　同单 2 分钟限一次（`42900 已催过啦`）

### POST /orders/:id/refund

鉴权：用户　｜　请求 `{ reason }`　｜　已支付订单可申请

### POST /orders/:id/finish

鉴权：用户　｜　确认完成并发积分

### POST /orders/:id/feedback

鉴权：用户　｜　请求 `{ score, content }`　｜　一单一次（重复 `40001`）

### 订单状态

`UNPAID` → `PAID` → `ACCEPTED` → `COOKING` → `READY` → `DONE`，可分支到 `CANCELED`

POST `/admin/coupons` 请求：

| 字段 | 说明 |
| --- | --- |
| `id` | 有则更新 |
| `name` `type` `value` | `CASH`/`SOUP`/`DISCOUNT`（`value`：CASH/SOUP 为分，DISCOUNT 为 1-99，88=8.8 折） |

- `40001 折扣券的折扣值应在 1-99 之间`
- `40001 无门槛或面额不应大于门槛金额`
- `40300 不能把券限定给自己无权管理的门店：st_dz`

POST `/admin/coupons/:id/grant` 请求：`{ userIds[] | phones[] | openids[] }`（三选一，上限 500）
